# Форма роста — адаптивный веб-сервис тренировок (версия 7)

Учебный MVP на **HTML, CSS, JavaScript и Python (Flask)**. Русскоязычный интерфейс адаптируется к компьютерам, планшетам и смартфонам. Сервер предоставляет REST API; данные сохраняются в `data/database.json`, аватары — в `static/uploads/`.

## Запуск без виртуального окружения `.venv`

1. Установи Python 3.10+ с сайта [python.org](https://www.python.org/downloads/). В Windows включи **Add Python to PATH**.
2. Распакуй архив целиком. Не открывай `static/index.html` напрямую: этот файл — только интерфейс, которому нужен Python-сервер.
3. Запусти `start.py` двойным щелчком. Если это не сработало, открой терминал в папке проекта и выполни `python start.py` (Windows также допускает `py start.py`).
4. Если Flask и Werkzeug ещё не установлены, программа установит их командой `pip --user` в пользовательский каталог Python. **Папка `.venv` не создаётся.** Для первой установки требуется интернет.
5. После запуска браузер откроет `http://127.0.0.1:5000`. Если не открылся автоматически, введи адрес вручную.
6. Не закрывай окно `start.py`, пока пользуешься сайтом. Для остановки нажми `Ctrl+C`.

### Если автоматическая установка не удалась

Из папки проекта выполни:

```bash
python -m pip install --user -r requirements.txt
python app.py
```

Затем открой `http://127.0.0.1:5000`. Если команда `python` не найдена в Windows, попробуй `py`.

## Демонстрационный вход

На публичной странице используй кнопку **«Посмотреть демо-кабинет»**. Она открывает демонстрационный профиль без необходимости вводить логин и пароль вручную. Для обычной работы можно создать собственный аккаунт.

## Возможности

- Публичная приветственная страница, вход и регистрация.
- Персональная панель с целями, недавними тренировками, опытом, уровнем и серией занятий.
- Создание, редактирование, просмотр и удаление тренировок.
- Каталог из 77 упражнений с инструкциями, GIF-демонстрациями, поиском и фильтрами; число упражнений на тренажёрах рассчитывается по данным каталога.
- 14 шаблонов занятий, включая утреннюю зарядку и профессиональные комплексы.
- История с календарём по дням месяца.
- Статистика, графики, личные рекорды и пользовательские диапазоны дат.
- Лидерборд с фильтрами по периоду и показателю.
- Уровни, опыт, еженедельные задания и 20 достижений.
- Редактирование имени, аватара, пароля и сценарий смены электронной почты.
- Адаптивная навигация, плавные анимации и поддержка `prefers-reduced-motion`.
- JSON REST API; локальные данные сохраняются на сервере.

## REST API

| Метод | Маршрут | Назначение |
|---|---|---|
| `GET` | `/api/health` | Проверка сервера |
| `GET` | `/api/me` | Текущий аккаунт |
| `POST` | `/api/auth/register` | Регистрация |
| `POST` | `/api/auth/login` | Вход |
| `POST` | `/api/auth/logout` | Выход |
| `GET`, `POST` | `/api/exercises` | Каталог и создание упражнения |
| `PUT`, `DELETE` | `/api/exercises/<id>` | Изменение/удаление упражнения |
| `GET` | `/api/templates` | Шаблоны тренировок |
| `GET`, `POST` | `/api/workouts` | История и создание тренировки |
| `GET`, `PUT`, `DELETE` | `/api/workouts/<id>` | Просмотр/изменение/удаление тренировки |
| `GET` | `/api/dashboard` | Главная панель |
| `GET` | `/api/stats` | Статистика и рекорды |
| `GET` | `/api/leaderboard` | Рейтинг |
| `GET` | `/api/missions` | Задания |
| `GET` | `/api/achievements` | Достижения |
| `PUT` | `/api/profile` | Имя пользователя |
| `POST`, `DELETE` | `/api/profile/avatar` | Аватар |
| `POST` | `/api/profile/change-password` | Смена пароля |
| `POST` | `/api/profile/change-email` | Запрос смены почты |
| `POST` | `/api/profile/confirm-email` | Подтверждение почты |

## Перед публичным запуском

Это учебный MVP. Для производственного запуска подключи реальный почтовый сервис для подтверждения электронной почты, задай случайный `SECRET_KEY`, включи HTTPS, добавь CSRF-защиту и ограничение попыток входа. JSON-хранилище подходит для локальной демонстрации; для нескольких одновременных пользователей лучше перейти на SQLite/PostgreSQL. Демонстрационные данные нужно удалить перед реальным развёртыванием.

Набор разрешает бесплатное использование изображений внутри приложений при обязательной видимой атрибуции «Exercise data by RepDB (repdb.co)»; подробные условия — в [лицензии RepDB](https://github.com/RepDB/exercise-dataset/blob/main/LICENSE-DATA.md).

## Финальная техническая ревизия

- Исправлены склонения числительных в основных динамических подписях; число упражнений на тренажёрах берётся из точного списка, а не из совпадений в названии оборудования.
- Инициалы демо-профиля больше не включают декоративный разделитель и слово «демо».
- Убраны предзаполненные логин и пароль; кнопка «Посмотреть демо-кабинет» сохранена. В демо-профиле нельзя менять пароль и адрес электронной почты.
- Полоса опыта заполняется после отрисовки главной страницы и анимируется, только если есть прогресс.
- Очередь достижений показывает все полученные награды по порядку; сервер возвращает сведения о повышении уровня и новых личных рекордах после сохранения тренировки.
- Дробные значения времени упражнения сохраняются. В подробностях тренировки показываются только показатели, подходящие выбранному упражнению, с корректными единицами и склонениями.
- Подписи дат на графиках формируются на русском языке; для количества тренировок используется целочисленная шкала. Подписи осей реже повторяются на длинных периодах.
- Для отсутствующих внешних иллюстраций добавлено локальное изображение `static/images/exercise-fallback.png`. GIF-анимации остаются внешними и требуют интернет-соединения.
- Неизвестные адреса `/static/...` возвращают настоящий код 404, а не HTML главной страницы. При редактировании упражнения проверяются название, группа мышц, направление, основной показатель и ссылка до сохранения изменений.
- Основные текстовые подписи интерфейса увеличены; заметка в форме тренировки занимает всю ширину строки. Иконки шаблонов выбираются по смыслу, а не по позиции в списке.
