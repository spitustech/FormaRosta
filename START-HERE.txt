ФОРМА РОСТА — БЫСТРЫЙ ЗАПУСК БЕЗ .venv

1. Установи Python 3.10+ (если ещё не установлен).
2. Распакуй архив полностью.
3. Открой папку forma-rosta.
4. Дважды щёлкни start.py. Если двойной щелчок не работает — открой терминал в этой папке и выполни: python start.py
5. Если Flask/Werkzeug не установлены, start.py установит их через pip --user в пользовательский каталог Python. Папка .venv не создаётся; при первой установке нужен интернет.
6. Когда сервер запустится, браузер откроет http://127.0.0.1:5000.

Не открывай static/index.html напрямую: это только оболочка интерфейса. Для входа,
тренировок, календаря и сохранения данных нужен запущенный Python-сервер.
Окно start.py должно оставаться открытым, пока пользуешься сайтом.

Для ручной установки библиотек используй:
    python -m pip install --user -r requirements.txt

Иллюстрации упражнений загружаются с сайта exercise-dataset.com. При отсутствии интернета используется локальная резервная иллюстрация. GIF-анимации загружаются отдельно из внешнего каталога и требуют подключения к интернету.
Источник: Exercise data by RepDB (repdb.co) — https://repdb.co


Финальная версия: каталог содержит 77 упражнений, в том числе 27 упражнений на тренажёрах; добавлены GIF-демонстрации, время начала тренировки, утренняя зарядка и профессиональные шаблоны. Подробности — в README.md.
